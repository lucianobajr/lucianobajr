### About me

I'm a full stack developer with a BSc in Computer Science and an MSc in Software Engineering, based in Belo Horizonte, Brazil. My work spans from algorithms and compilers to hardware architecture and applied data analysis — I like understanding systems from the logic gate up to the API layer.

Most of what I build starts as a hard problem I want to reason through properly: a graph optimization, a pipelined processor, a small programming language. A few of those explorations below.
